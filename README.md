# جدول الضرب (TimesTable)
تطبيق iPhone لحفظ جدول الضرب بالاسترجاع من الذاكرة والتكرار المتباعد (صناديق لايتنر).
1. ارفع كل الملفات إلى مستودع GitHub جديد.
2. ادخل Actions ثم Build IPA ثم Run workflow (أو يبدأ تلقائيًا مع كل push).
3. حمّل TimesTable.ipa من فرع ipa أو من Artifacts وثبّته بـ Sideloadly.
